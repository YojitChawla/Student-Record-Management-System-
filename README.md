Student Record Management System
About the Project
The Student Record Management System is a simple beginner-level project written in the C programming language. It helps manage student records using arrays, strings, functions, loops, conditional statements, and recursion.
Features
- Add a student record
- Display all student records
- Search for a student by ID using recursion
- Update student details
- Delete a student record
- Calculate the average marks of students
- Menu-driven program
Student Details
Each record stores:
- Student ID
- Student Name
- Course
- Marks
Concepts Used
- Basic C programming
- stdio.h for input and output
- string.h for string operations
- Arrays
- Strings
- Functions
- Recursion
- for and do-while loops
- if-else and switch statements
Requirements
- A C compiler such as GCC
- Any code editor or IDE (e.g., Code::Blocks, Dev-C++, VS Code)
How to Compile and Run
Using GCC
1. Save the source code as student.c.
2. Open a terminal or command prompt in the folder containing the file.
3. Compile the program:
   gcc student.c -o student
4. Run the program:
   Windows
   student.exe
   Linux / macOS
   ./student
Menu Options
Option	Operation
1	Add Student
2	Display Students
3	Search Student
4	Update Student
5	Delete Student
6	Calculate Average Marks
0	Exit


Limitations
- The program can store up to 100 student records.
- Names and courses should be entered as single words.
- Records are stored in memory only. They are lost when the program exits.
- Duplicate student IDs are not checked.
Project Purpose
This project is designed for beginners to practice fundamental C programming concepts through a simple student record management application.
